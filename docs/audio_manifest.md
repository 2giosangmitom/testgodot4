# Audio manifest — names are a contract

Code calls `AudioDirector.play_sfx("<name>")` etc. Track D must deliver every file below
(`.ogg`, mono; sfx/voice 22050 Hz, ambience/music 22050 Hz or 32000 Hz; 11025 Hz for "radio"/"cheap" ones).
Other tracks may ONLY use names from this list. Need a new one → put it in your report.
